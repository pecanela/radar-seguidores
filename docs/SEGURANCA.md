# Segurança e divulgação de problemas

- Não publique senhas, cookies, capturas contendo sessões, IDs reais ou exports de seguidores em issues públicas.
- Para erros sem dados pessoais, informe browser/versão, passos para reproduzir e mensagem de erro.
- Falhas que possam afetar contas devem ser reportadas reservadamente ao mantenedor do repositório (configure *Private vulnerability reporting* no GitHub antes da publicação).
- Este projeto não executa unfollow em massa e requer confirmação individual.
- Não há automatização para contornar desafios de login ou bloqueios de taxa.
- Não desative Play Protect ou proteções do navegador para usar o projeto.
