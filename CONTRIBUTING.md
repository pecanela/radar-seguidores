# Contribuindo

PRs são bem-vindos para correções, testes e acessibilidade. Mantenha as permissões mínimas, evite dependências externas no runtime, não implemente automação de unfollow em massa, não exponha tokens/cookies e não adicione telemetria sem discussão pública e atualização da política de privacidade.

Comandos: `npm test`, `npm run build`. Consulte `docs/PUBLICACAO.md` para checklist de lançamento.
